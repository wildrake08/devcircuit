## Claim boundary

The controlled local cycle demonstrates the platform’s state transitions, authority rules, artifact binding, tests, local deployment, monitoring, and normative graph. It does not establish production adequacy for an arbitrary generated system.

Production adequacy is bounded to the exact signed system specification, accepted artifact, authorized deployment, target environment, evidence producer, observation freshness, sustained outcome periods, supply-chain controls, recovery evidence, operational state, and external closure decision. Evidence expiry or a relevant change reopens the affected assurance.

The local reference uses filesystem-protected HMAC identities and an internal bearer-session vault. Production use still requires organizational identity, MFA, protected external signing keys, protected runners and environments, repository rulesets, and authentic target-system adapters. DevCircuit does not claim an operating-system sandbox, universal quality certification, or permanent production adequacy.
